# 可移植 Agent 资产

本目录存放不依赖单一模型厂商的 Agent 工作资产。

```text
agent/
├── skills/      可复用的任务 SOP、模板和验收规则
├── policies/    安全、数据和业务边界
└── workflows/   多步骤或多角色流程说明
```

## 设计原则

- 用自然语言描述意图，不把某个平台的工具名写成唯一实现。
- 把输入、输出、前置条件、失败处理和验收标准写清楚。
- 厂商专属配置放在独立适配层，不复制核心业务规则。
- Skill 不能绕过 `AGENTS.md`、权限系统或用户审批。
- MCP 连接信息只能记录服务用途和所需环境变量，不能提交真实凭据。

## 建议工作流

1. 先在日常任务中验证流程；
2. 当相同流程反复出现时，将其提炼为 Skill；
3. 为 Skill 添加示例和可验证的完成标准；
4. 分别为 DSH、Codex 或 Claude Code 编写轻量适配；
5. 定期检查流程是否仍符合业务与安全要求。
